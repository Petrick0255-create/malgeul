# 말글

말하면 글이 되는 브라우저 기반 음성 받아쓰기 웹앱입니다.

## 주요 기능

- 한국어, 영어, 일본어, 중국어 음성 인식
- 실시간 중간 결과와 연속 받아쓰기
- 문장부호 음성 명령
- 자동 임시 저장, 글자·단어 수, 녹음 시간
- 클립보드 복사 및 TXT 다운로드
- 모바일 반응형 UI 및 PWA 지원

## 실행

HTTPS 또는 localhost 환경이 필요합니다.

```bash
python3 -m http.server 4173
```

Chrome 또는 Edge에서 `http://localhost:4173`을 열고 마이크 권한을 허용하세요.
